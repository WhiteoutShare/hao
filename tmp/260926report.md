# 🏰 王城スコア稼ぎレポート

**参加時間：**
約3:45分参加

**資源消費：**
肉 約700M、および同程度のその他資源を消費。

**操作方法：**

* 王城へ直接攻撃
* 兵士の比率：**1:1:1** または **6:2:2**
* 1回目の攻撃 → 治療 → 2回目の攻撃 → 再度治療
* 上記の流れを繰り返す

**最終結果：**

* 🏆 総ポイント：**83M+**
* 📊 ランキング：**10位**

**その後への影響：**
その後も肉を含め、同程度の資源が約 **100M** 残っていたため、現時点では兵士の訓練や建設への**大きな影響はありませんでした**。

**治療状況：**
1回あたりの治療が即時完了するまでの時間は、以下のように変化しました。

**37分 → 25分 → 15分**

後半になるにつれて治療時間が短くなりました。
協力人数など、何らかの要因が影響している可能性があります。
