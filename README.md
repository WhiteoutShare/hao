# サーバールール共有

## サーバールール

- 同盟所属者への都市攻撃・タイルキル禁止
- 同盟施設への無言攻撃禁止
- レベルと効果同じのステーション重複保有禁止
- 旗はｽﾃｰｼｮﾝの接続は2本程度とし、なるべく点接続を意識すること。
- 攻撃について違反時は相手盟主、幹部へ報告後24時間連絡なし→報復措置ありです。

### 誤攻撃について

また、他同盟の都市・建物・採集中の部隊などへの誤攻撃は、同盟間のトラブルにつながる可能性があります。

誤攻撃した場合は、速やかにR4以上までご連絡ください。

### 本部・ニックネームについて

より楽しく快適な同盟づくりのため、本部付近への移転とニックネーム変更にご協力をお願いします。
