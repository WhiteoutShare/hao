# 【サーバールール共有】

## サーバールール

- 同盟所属者への都市攻撃・タイルキル禁止
- 同盟施設への無言攻撃禁止
- レベルと効果同じのステーション重複保有禁止
- 旗はｽﾃｰｼｮﾝの接続は2本程度とし、なるべく点接続を意識すること。
- 攻撃について違反時は相手盟主、幹部へ報告後24時間連絡なし→報復措置ありです。

### 誤攻撃について

また、他同盟の都市・建物・採集中の部隊などへの誤攻撃は、同盟間のトラブルにつながる可能性があります。

誤攻撃をしてしまった場合や、逆に攻撃されてしまった場合は、恐れ入りますがR4以上までご連絡ください。

### 本部・ニックネームについて

より楽しく快適な同盟づくりのため、本部付近への移転とニックネーム変更にご協力をお願いします。

# 【ステーションの部隊編成について】

保護工程ステーションの防衛失敗が増えています。  
Lv.5以下の兵士は、できるだけ高レベル兵へ昇格をお願いします。

隊長以外で参加する場合は、英雄スキルも重要です。
> ※集結に乗る場合は左側の英雄の第一遠征スキルのみ適応されます。

- 攻撃：ジェロニモ ＞ ジェシー ＞ ジャセル ＞ ソユン
- 防衛：パトリック ＞ セルゲイ ＞ ジャスミン ＞ バシティ

上記英雄を**編隊の左側（1人目）**に設定して、編隊を登録しておきましょう。

# 【クレイジージョイについて】

## 事前準備
- 採集部隊を帰還させる
- 城門の自動駐屯をONにして、駐屯英雄は出征出来ませんにチェック
- 部隊をすべて盟友へ駐防し、自分の都市には兵士を残さない
- イベント開始時に負傷兵をすべて治療し、全部隊を派遣する。
- イベント中に兵が負傷しても、終了まで治療しない

## 攻撃対象
- 7/14/17波：オンライン中の領主のみ攻撃
- 10/20波：雪原本部を攻撃。開始前に各自3万兵を駐屯し、ポイントを獲得

## 防衛
- 2回防衛失敗した領主は、以降攻撃されません
- 2回失敗後は、他の盟友へ駐防してポイントを獲得できます

## 消火
- 無料消火は1人1回。2回目の失敗後に使用
- イベント後、燃えている盟友の消火にもご協力ください

# 【兵器工場争奪戦】
## 事前準備

- 入場前に、ペットスキルの「ユキヒョウ」「タイタン」を使用する

## 作戦・方針

- クールタイムはあるが無料で都市移転できるので、どんどん移転する
- 集結は遠いところからでは間に合わないため、積極的に移転する
- 理想は1つの施設を3～4人で攻防する形。状況に応じてどんどん移転する
- 施設を奪ったり奪われたりした際は、弾が周囲に飛び散るので必ず拾う
- 中央の王室軍事工場は大量にポイントを獲得できるため、解放されたら移転して占領する

#  【同盟争覇戦について】

## 事前準備

- エントリー前に、ペットスキルの「ユキヒョウ」「タイタン」を使用する

## エントリー時の英雄

争覇戦では、エントリーした3人の英雄の**すべての遠征スキルが発動**します。  
そのため、遠征スキルに攻撃系・防御系の効果を多く持つ英雄を優先して配置してください。

- フリントLv.4以上の場合  
　→ フリント / ジャスミン / バシティ

- ジャスミンLv.4以下 ＋ パトリックLv.4以上の場合  
　→ ジャスミンをパトリックに変更可
